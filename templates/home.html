API Documentation

POST /payouts-create

Create a new payout. Requires X-API-Key header for authentication.

GET /payouts/{payout_id}

Retrieve payout details by ID. Requires X-API-Key header.

GET /stats/summary

Get partner statistics including payout counts and daily amounts.

POST /internal/executor/claim

Executor endpoint to claim payout tasks for processing.
